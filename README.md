# owenolanda.com

Página personal y CV interactivo de **Owen Olanda**, desarrollador web y de software.

Hecha a mano con HTML, CSS y JavaScript, sin frameworks.

- `index.html`: la página publicada (generada).
- `src/index.html`: el código fuente de la página.
- `assets/`: video de fondo e imagen de respaldo.
- `build.py`: genera `index.html` a partir de `src/index.html` (`python3 build.py`).

Pista: escribe "never settle" en la página.
